onevid — UX Scenario (QA)

1. App summary

onevid is a video streaming player. It runs in the TV browser (hosted web app) and is operated with the remote control (D-pad + OK + Back).

2. Test credentials

Sign-in uses a device code (no email/password typing on the TV). The demo account to approve the device is provided in the "Note for Tester" field of this submission.

3. Step-by-step

  1. Launch: the app opens on the sign-in screen, showing a QR code and an 8-character code.
  2. Authorize the TV:
    1. Scan the QR with a phone (opens the approval page with the code pre-filled), or open the shown URL and enter the code manually.
    2. Sign in with the demo credentials and press "Approve".
    3. The TV detects the approval and enters the catalog automatically.
  3. Browse the catalog (remote): move with the D-pad across the featured carousel and the rows. The focused item is highlighted. Press OK on a title to open its detail.
  4. Play: on the detail screen, press "Play". The video starts full screen. Remote controls: Play/Pause, seek, Back to return.
  5. Back and exit: the Back button navigates back through the screens; from the home screen, Back exits the app.

4. Notes for the reviewer

Requires an internet connection (content loads over the network). The sign-in code expires; the app generates a new one on its own.
